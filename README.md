# ClipIt Sports Highlights

ClipIt is an easier way to record and gather sports highlights in real time. The idea is to set up
the phone on a tripod or handheld filming and start a recording. When a moment worth saving for later
happens such as a great play, error, or funny moment, you hit the "ClipIt" button which will save the
last "x" amount of seconds between 5-60s into a highlight video. When you finish the game, you can stop the
recording and you'll have all those clipped moments in your pocket as you walk off the field!

## Instructions for Build and Use

Steps to build and/or run the software:

1. Connect your phone to Xcode or be added to the Test Flight tester group.
2. If connected to Xcode, hit command R. If on test flight, install the app and open it.
3. When the app opens for the first time, it'll ask permissions for camera, microphone, and bluetooth so that
you can record and use ClipIt.

Instructions for using the software:

1. Use the "Record" screen to film and clip highlights. You can set the clip duration, camera quality, and zoom.
2. The "Library" screen is where you'll find the Clip Library of all your recordings. You can filter between
All, Highlights, Favorites, Reels, and Original Videos.
3. Tap any highlight and you can watch back the great moment. Missed something? No worries! You can always edit
the clip afterwards as long as the original video is kept.
4. The "Device" screen is where you'll find the handheld bluetooth ClipIt Button that you can purchase
separately. You can see the connected state and battery of the device.
5. The settings page is where you'll find everything you need to run the app as well as a developer note and
Q&As.
